About QuickNotes

QuickNotes is a simple web application for capturing and organising notes quickly. It helps users record ideas and reminders before they disappear.

How to use QuickNotes

  1. Open the QuickNotes application.
  2. Type your note in the note input box.
  3. Click the Add Note button to add your note.

Features

  • Quickly add notes.
  • View your saved notes.
  • Simple and easy-to-use interface.
  • Keyboard-friendly controls.

Keyboard shortcuts

Shortcut Action
Enter Add the note
