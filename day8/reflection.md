# Day 8 Reflection

The most difficult concept in this course was understanding how a system can handle many requests at the same time without producing incorrect results. I overcame this by studying how transactions, row locking, and database constraints work together. I learned that checking seat availability in the browser is not enough because two requests can arrive almost simultaneously. The database must make the final decision.
